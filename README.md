# fly-the-w

シカゴ・カブスに関する試合結果・ニュースを自動で収集し、
まとめて表示することを目標とした個人開発プロジェクトです。

## 目的

- 好きなプロスポーツチーム(シカゴ・カブス)の情報を一箇所にまとめたい
- AIを用いないPythonの実装経験を積むための学習プロジェクトとして開始
- Gitの経験を積む
-

## 開発方針

- **Pythonのコード生成にはAIツールを使用しません**。
  Pythonの実装経験を積むことがこのプロジェクトの主目的のため、
  ロジックは自力で書くことを方針としています
- 調べ物(エラーの原因調査、ライブラリの使い方の確認など)にはAIツールや検索エンジンを活用しています
- HTML/CSSなど装飾面については、AIツールの支援を受ける場合があります
- ニュース記事は本文を保存・表示せず、タイトルとリンクのみを取得しています
  (著作権への配慮)
